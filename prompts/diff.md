# 比对任务

将提取的候选条目与现有的 GTD 清单进行比对，输出更新后的完整清单内容。

## 比对规则

1. **新增**：候选条目在现有清单中找不到语义相似的内容 → 添加到对应板块
2. **合并**：候选条目与现有条目语义相关，但提供了新信息 → 更新现有条目的描述
3. **跳过**：候选条目与现有条目语义相同 → 保留原条目不动
4. **待讨论**：不确定如何处理的条目 → 在条目后附加「（待讨论）」标记

## 格式要求

板块顺序：
1. 日程
2. 下一步行动
3. 等待回复
4. 悬而未决

优先级标注格式：`> 优先级：高/中/低`

各板块内按优先级降序排列（高 → 中 → 低）。

空板块保留标题但留空（保留格式一致性）。

## 输出

直接输出完整的更新后 Markdown 清单内容，不做额外解释。
