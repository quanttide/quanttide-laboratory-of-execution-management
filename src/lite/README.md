# 桌面待办清单 — 源码归档

> 常驻桌面的待办浮窗小工具，Python + tkinter 实现，置顶、半透明、可拖拽、可缩放。

## 项目结构

```
E:\工作\桌面待办清单\
├── todo_desktop.py        # 主程序源码（本归档文件内含完整副本）
├── 启动桌面待办.bat        # 双击启动脚本
├── tasks.json             # 任务数据（程序自动生成，UTF-8）
└── 桌面待办清单_整理源码.md # 本归档
```

## 功能清单

- 添加任务（回车或点「＋」），支持优先级（高/中/低）
- 任务可设开始日期、截止日期（YYYY-MM-DD），自动显示「今天开始 / X天后开始 / 逾期X天 / 今天截止」
- 勾选完成 / 标记未完成，右键菜单可改优先级、改日期、编辑、删除
- 一键清理已完成任务，底部状态栏显示统计
- 窗口置顶开关、拖拽移动、右下角缩放、鼠标滚轮滚动列表
- 数据本地保存（tasks.json），重启不丢失

## 使用方式

```bat
:: 双击启动
E:\工作\桌面待办清单\启动桌面待办.bat
```

需 Python 3.10+（tkinter 内置，无需额外依赖）。

## 启动脚本（启动桌面待办.bat）

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
start "" pythonw.exe "%~dp0todo_desktop.py"
```
